# ThiraiHub

A movie-ticket booking and resale marketplace. The Angular client runs against an
in-memory mock API (no backend needed).

```
show-hub/
└── client/   Angular app
```

## Run

```bash
cd client
npm install
npm start        # ng serve, http://localhost:4200
npm run build    # ng build, output in client/dist
npm test         # ng test (Vitest)
```

See [client/README.md](client/README.md) for the full Angular CLI reference.
